# Party Games (standalone)

Это **самостоятельный** React-проект.

Если ты хочешь работать только со своим проектом (без `effective-mobile-ui-tests`),
просто открой папку `party-games-app` как отдельный root в VS Code/WebStorm.

## Быстрый старт

```bash
npm install
npm run dev
```

Открой `http://localhost:5173`.

## Отдельный root вне этого репозитория

Можно вынести проект в отдельную папку командой из корня репозитория:

```bash
# Linux/macOS/Git Bash
bash scripts/extract-party-games-project.sh

# Windows PowerShell
.\scripts\extract-party-games-project.ps1
```

Скрипт создаст рядом папку `../party-games-project`.
