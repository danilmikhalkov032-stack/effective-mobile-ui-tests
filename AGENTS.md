# AGENTS.md

## Scope
Эти инструкции применяются ко всему репозиторию.

## Контекст проекта
- Основной Python Playwright-набор в `tests/` относится к legacy-части репозитория.
- Пример React-архитектуры находится в `examples/party-game-host/` и является изолированным reference-кодом.

## Какие проверки валидны для `examples/party-game-host`
При изменениях только в `examples/party-game-host`:
1. **Не запускать** `python -m pytest -q`.
2. Проверять только релевантные файлы в `examples/party-game-host`.
3. Если в репозитории нет JS toolchain (`package.json`, lock-файлы, npm/pnpm/yarn scripts),
   то писать в отчёте: **автоматизированные проверки недоступны**, валидация выполнена
   через code review изменённых файлов.
4. В таком случае допустимые проверки:
   - структурная проверка файлов/импортов,
   - чтение и ручная валидация логики,
   - отсутствие синтаксически повреждённых фрагментов (по коду и импортам).

## PR/отчёт
- В отчёте явно указывать, что изменения относятся только к `examples/party-game-host`.
- Не смешивать результаты с legacy Python Playwright тестами.
